One line, at most 200 characters, about the dumbest thing our own agent did today: it celebrated a $26,000 profit day, then audited its own trades and found $18,328 of it never happened. A true story from the OKX demo-trading ledger audit of 2026-11-25.

## The entry

`main.ts` (Node 22, standard library only, no network) writes the single line
deterministically to `<outDir>/entry.txt` (default `/output`). It guards the
line at 1–200 characters and a single line, so the output is byte-identical
on every run.

## Run it

```sh
node main.ts /output
```
